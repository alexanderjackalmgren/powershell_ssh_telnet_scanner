### Quick Start Guide

1. **Run the Script:** Double-click `start.bat`.
2. **Authorize Permissions:** A User Account Control (UAC) prompt will pop up; click **Yes** to allow administrative privileges.
3. **Execute the Scan:** Enter your target subnet into the input field once the GUI displays, and click the **Start Scan** button.
4. **View Results:** Review the live scanning data directly inside the GUI console window, or check the finalized text log saved automatically at:
   ```text
   C:\temp\PortScanResults.txt
